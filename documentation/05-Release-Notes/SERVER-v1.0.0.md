# RecipeHub Server 1.0.0

## Overview

This release note describes the Express API and MongoDB backend package declared as version `1.0.0` in this repository. The backend uses Node.js, Express, and the native MongoDB Node.js driver.

## Included functionality

- Email/password registration and login, Google authentication integration through Better Auth, JWT authentication middleware, cookie parsing, and administrator authorization.
- Recipe creation, retrieval, editing, and deletion; pagination, search, category filtering, featured and popular lists; likes, favorites, and reports.
- Ratings and written reviews embedded in recipe documents, with a 1–5 rating, one editable review per authenticated user/recipe, public averages/counts, and reviewer ID/email redaction.
- Premium recipe and membership checkout integration, payment verification, Stripe webhooks, and purchase records.
- Admin statistics, user listing, role and block management, recipe management, featured controls, report handling, and transaction listing.
- Exported Express application in `app.js`; MongoDB connection and HTTP startup in `index.js`.

## Automated checks

- Backend Jest/Supertest/MongoMemoryServer suite: **20 passed, 0 failed, 0 skipped** in the security regression verification run.
- The tests cover health, recipe listing and creation, premium recipe access locking, review privacy/validation/editing, likes, favorites, reports, admin authorization and role management, and invalid payment request handling.
- The in-memory Mongo URI is generated by the harness and passed to the environment before database/app imports. Test mode requires an exact URI match and a test database name. Test users and JWT secrets are synthetic.
- Checkout tests stop at request validation. No real Stripe transaction, Stripe success flow, external OAuth request, or production database access was tested.

## Documentation and deployment

The combined repository includes the ER diagram, architecture diagram, screenshots, usability evaluation, and participant evaluation template. Existing documentation lists `https://recipehub-server-dr3a.onrender.com` as the backend URL; deployment availability and the deployed revision were not checked.

## Known limitations

- Stripe payment success behavior is implemented but was not exercised through an external Stripe session in the automated suite.
- Google sign-in and live MongoDB deployment were not tested.
- Full client lint reports existing issues; see the client release notes and verification report.
